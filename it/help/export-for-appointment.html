Portare le registrazioni delle iniezioni a un appuntamento

Le tue registrazioni lasciano Vialog solo quando le esporti. Ci sono tre modi: un report PDF da leggere insieme a qualcuno, file CSV per un foglio di calcolo, e un file di backup che sposta tutto su un altro telefono.

Tutti e tre sono in Impostazioni › Esportazione, backup ed eliminazione. Il link Prepara un report nel Diario apre la stessa schermata.

Scegliere cosa includere

Scegli l'intervallo di date e spunta cosa includere: iniezioni, somministrazioni saltate, check-in, misurazioni corporee (finché sono mostrate nell'app), risultati di laboratorio e la quantità disponibile. Le tue routine, i loro programmi e le tue etichette dei siti vengono sempre incluse con ciò che è spuntato, così le registrazioni si possono leggere da sole.

Un report PDF per un appuntamento

Il report PDF è un elenco leggibile delle tue registrazioni nell'intervallo, con grafici se li vuoi. Prima di crearlo puoi:

  • scegliere tutte le routine o una sola;
  • scegliere quali grafici includere;
  • scegliere quali check-in includere, così una nota privata resta fuori;
  • scrivere Domande o note per il tuo appuntamento, che compaiono nel report.

Tocca Anteprima PDF per leggerlo prima sul telefono, poi condividilo come preferisci: AirDrop, Mail, Messaggi, File o stampa. Queste scelte restano sul tuo telefono per il prossimo appuntamento. Il report PDF fa parte di Vialog Pro, un acquisto unico.

Il report mostra cosa hai registrato, quando e con quale frequenza. Non interpreta nulla: cosa significa è una conversazione da fare all'appuntamento.

File CSV per un foglio di calcolo

Esporta file CSV è gratuito. Crea un file per ogni tipo di registrazione, che Numbers, Excel o Fogli Google aprono direttamente. Ogni riga mantiene la quantità esattamente come l'hai digitata, nella sua unità, con un orario esatto (con lo scostamento del fuso orario, o in UTC), il momento in cui è stata inserita e un ID stabile, così la stessa registrazione si può abbinare tra un'esportazione e l'altra.

Le registrazioni tenute in un'altra app o in un foglio di calcolo possono entrare nel verso opposto, con Importa cronologia da CSV. Abbini tu le colonne, ogni riga viene controllata prima di salvare qualsiasi cosa, e le righe già presenti vengono ignorate.

Un backup per passare a un nuovo telefono

Backup di tutte le registrazioni crea un unico file con tutto, foto incluse, e ti permette di salvarlo dove vuoi, per esempio in File o iCloud Drive. Sul nuovo telefono, installa Vialog e usa Ripristina da un backup. Un ripristino sostituisce tutto su quel telefono con il contenuto del file, e non cambia nulla se il file non è valido per intero.

Vialog può ricordartelo nell'app ogni 30 giorni. Registra la data della tua ultima condivisione completata, ma non può vedere se il file è stato conservato, né se il backup iCloud del telefono è stato eseguito.

Vialog Pro non è nel backup: su un nuovo telefono usa Ripristina acquisti in Impostazioni › Vialog Pro.

Tenere al sicuro i file esportati

Un file esportato è leggibile da chiunque lo abbia. Vialog non può proteggere un file una volta uscito dall'app, quindi condividilo solo con le persone a cui è destinato ed elimina le copie che non ti servono più.

Vialog è un registro personale. Non interpreta le tue registrazioni e non consiglia modifiche.
