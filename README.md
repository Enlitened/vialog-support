# Vialog support

The website for Vialog (iOS): the landing and support page, the privacy policy and the help
articles. Vercel serves it at https://vialog.club/ and redeploys on every push to `main`; GitHub
Pages still serves it at https://enlitened.github.io/vialog-support/, where builds up to 1.4 link.

The source of truth is `docs/site/` in the Vialog repository, and `docs/SITE.md` there says how
to publish. Edit there and copy here; never edit here first.
