Moving an injection log from a spreadsheet

If you have kept your injections in a spreadsheet, on paper you have typed up, or in another app that exports CSV, Vialog can bring those records in. You match the columns yourself, see every row before anything is saved, and the import is free.

The import is in Settings › Export, backup and delete › Import history from CSV. The welcome screen offers it too, under Restore backup or import history. To move everything from another iPhone that already has Vialog, restore a backup instead; the import is for records kept somewhere else.

Getting the file ready

Numbers, Excel and Google Sheets can all save a sheet as CSV. Each row is one record; the first row holds the column names. Vialog needs three columns and can take a few more:

  • Date and time, with its time zone, in the form 2026-09-01T08:00:00+10:00. A date with no time, or a time with no zone, is refused rather than guessed, and so is a date later than now.
  • Amount, the number you recorded, exactly as written. If your sheet writes 0,5 rather than 0.5, turn on Amounts use a decimal comma.
  • Unit: mg, mcg, mL, IU or device for a device's own markings, with a Device description column to say which device.
  • Site and Note, both optional.

Nothing is converted. A record comes in with the amount and unit its row gives, as every record in Vialog does. A file can hold up to 5,000 rows and must be smaller than 2 MB.

Matching the columns

Choose Injections as the record type, the delimiter your file uses (comma, semicolon or tab), then Choose CSV. Vialog matches columns with familiar names, such as date, amount, unit, site and note, by itself; check each one under Match columns and change any it got wrong, or set a column to Not mapped.

Records go into one routine at a time. Pick it under Import into routine, or tap Create a routine to make it there and then. If one file holds several routines, map the column that names them as Source routine and choose which one this import takes; run the import again for the next.

Checking before anything is saved

Preview import shows how many rows are valid, any errors with the row they are on, how many records are new, and how many match a record already there and will be skipped. The first 20 rows are shown in full. Nothing is imported while any row has an error: correct the file or the matched columns and preview again. Then tap Import reviewed records.

Because matching records are skipped, importing the same file twice adds nothing the second time. An injection you removed in Vialog is not brought back by importing it again.

What an import does not do

  • Imported injections are historical records. They do not mark a scheduled entry as recorded.
  • They do not count down the amount on hand.
  • They leave every record already in Vialog as it is.

Body measurements

Weight, body fat and lean mass come in the same way with Body measurements as the record type. A Type column says which each row is; without one, every row is a weight. Units are kg or lb for weight and lean mass, and % for body fat. If you share body measurements with Health, imported ones are shared too; readings that came from Health in the first place are left out.

Vialog is a personal record. It keeps what you bring in as you wrote it, and does not recommend a product, an amount or any change to your routine.
